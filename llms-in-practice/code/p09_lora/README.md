# Episode 9 · Fine-Tuning vs Prompting, and LoRA in One Picture

Teach the tiny GPT from *How LLMs Work* (trained on Shakespeare) a new style, made-up recipes, by full fine-tuning
and by LoRA, written by hand in about 15 lines.

```bash
pip install -r requirements.txt
python lora.py
```

CPU only. `base.pt` (the Shakespeare base model, 3.2 MB) is included, so the script starts straight away; delete it
to retrain the base model (3,000 steps, about 25 minutes). `recipes.txt` is generated by `make_recipes.py`.

Results (600 fine-tuning steps):

| | trainable parameters | recipe loss | Shakespeare loss |
|---|---|---|---|
| base model | – | 2.77 | 1.60 |
| full fine-tuning | 818,241 (100%) | 0.25 | 4.40 (forgot) |
| LoRA, rank 4 | 32,768 (4.0%), 128 KB file | 0.27 | 3.92 with the adapter, **1.60** with it switched off |

Try `add_lora(tuned, r=1)` (8,192 parameters, recipe loss 0.39) or a larger rank.
