# How LLMs Work

A 14-episode series (about 32 minutes) that builds up a large language model from scratch:
tokens → embeddings → position → attention → MLP → transformer blocks → probabilities → training → a real tiny GPT,
plus two bonus episodes on the KV cache and on turning a GPT into a chatbot.

Running example throughout: **"The cat sat on the" → "mat"**. Episodes 11–12 use the real
[tiny GPT](tiny_gpt/) in this folder: its code, its training curve and its generated text are shown on screen.
Viewers who want the underlying math first can watch the [Foundations](../foundations/) pre-series.

## Files

- `vNN_script.py`: title, tagline and the narration, one string per section. Readable version: [NARRATION.md](NARRATION.md).
- `vNN_scene.py`: the Manim scene, cued to narration word timestamps.
- `voice/vNN/sections.json`: section durations and word timestamps (the `.wav` files are regenerated by `./narrate.sh`).
- `tiny_gpt/`: the ~100-line character-level GPT trained for episodes 11–12.

Render an episode from the repo root: `./render.sh how-llms-work v05` (see the [main README](../README.md)).
