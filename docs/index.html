Educational Video Uploader

A small owner-operated command-line tool that uploads Gianluigi Lanciotti's own educational videos to the owner's YouTube channel and organizes them into playlists, using the YouTube Data API (YouTube API Services). It has no public users and offers no hosted service.

The videos it uploads are the How LLMs Work and Foundations series; their source code and study-guide PDFs are in the educational-videos repository.
