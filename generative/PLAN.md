# How Generative Models Work: Images and Sound

The sixth series. The earlier series cover language models end to end; this one covers models that **make images and
sound**. Same format as the others: ~2–2.5 minute narrated Manim episodes, a study-guide PDF, and runnable code for
every number on screen. Ids `gNN`, code in `code/gNN_<topic>/`.

Everything trains or runs on a CPU (16 cores, no GPU). The image episodes use **Shapes**, a small synthetic dataset
made by our own code (32×32 colored circles, squares and triangles in different positions, each with a caption such as
"a red circle at the top left"). It is license-free, trains in minutes, and its captions make text-to-image possible
without scraping anything. The sound episodes use speech generated by the Kokoro voice that narrates the series.

Prerequisites: Foundations (vectors, probability, gradients, waves) and How LLMs Work (tokens, attention, training).
